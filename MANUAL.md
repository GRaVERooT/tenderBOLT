# Руководство пользователя — tenderBOLT v0.1

**Статус:** демонстрационный MVP. Никакой реальной подачи заявок, автоматического сбора и серверного хранения данных в этой версии нет.

## 1. Где открыть и как войти

- Репозиторий: https://github.com/GRaVERooT/tenderBOLT
- Адрес после успешного включения Pages: https://graveroot.github.io/tenderBOLT/
- Включение/проверка Pages: https://github.com/GRaVERooT/tenderBOLT/settings/pages
- Демонстрационный логин: **demo@tenderbolt.kz**
- Демонстрационный пароль: **Bolt2026!**

**Безопасность:** Это общие демонстрационные реквизиты, проверяемые только в JavaScript браузера, а не серверная авторизация. Любой человек может изучить исходный код и обойти экран входа. Даже приватный репозиторий не гарантирует приватности сайта GitHub Pages. Не вводите настоящие пароли, коммерческие предложения, персональные или конфиденциальные данные.

## 2. Первый запуск и рабочие пространства

1. Откройте сайт. Введите указанные выше демо-реквизиты.
2. В верхней панели выберите пространство «Мой первый проект».
3. Нажмите «+ Новое», чтобы создать независимое пространство для другого клиента или направления.
4. На главном пространстве есть восемь **вымышленных** записей с номерами DEMO-001...DEMO-008.
5. На узком экране меню шести этапов прокручивается горизонтально.

Лоты и критерии независимы для каждого пространства. Переключатели источников общие.

## 3. Шесть этапов работы

### Этап 1. Источники
Включите или выключите показанные источники (Госзакуп РК, Самрук-Казына, другие площадки). Это **только настройки интерфейса**: синхронизации, ботов, подписок и API-запросов нет. Перейдите на этап 2 для ручной работы.

### Этап 2. Сбор лотов
- Реестр содержит номер, источник, наименование, заказчика, бюджет, дедлайн, статус.
- Поиск — по номеру, названию, заказчику, источнику; есть фильтр статусов.
- «+ Лот» — добавление своей закупки вручную.
- «Импорт CSV» — массовое добавление. Формат: UTF-8, заголовки number;title;customer;budget;deadline;source и затем записи:

    number;title;customer;budget;deadline;source
    LOT-101;Аудит ИБ;Тестовый заказчик;12000000;2026-12-20;Ручной импорт
    LOT-102;Поставка серверов;Тестовый заказчик;24000000;2026-12-25;Ручной импорт

Разделитель — точка с запятой или запятая. Кавычки стандартного CSV поддерживаются. Даты — YYYY-MM-DD, бюджет — целое число в тенге. За один импорт обрабатывается максимум 1000 строк; неверные строки и повторяющиеся номера пропускаются. Кнопками можно отобрать или отклонить закупку.

### Этап 3. Анализ ТЗ
Введите ключевые фразы через запятую, минимальный и максимальный бюджет. Нажмите «Сохранить критерии». Система даёт до 100 баллов:
- +23 за совпавшую ключевую фразу в названии или заказчике;
- +20 если сумма в диапазоне;
- +10 если дедлайн не ближе 10 дней.

Это прозрачный **скоринг по метаданным**, не анализ PDF/ТЗ, не ИИ-экспертиза и не прогноз победы.

### Этап 4. Отбор
Слева — лоты в работе, справа — очередь. Можно перевести лот в работу, отклонить, вернуть, записать заметку. Отклонённые выведены отдельным блоком.

### Этап 5. Предложение
Для отобранных закупок можно записать ориентировочную себестоимость и рассчитать грубую валовую разницу с бюджетом заказчика; поставить три отметки готовности: ТЗ, документы, экономика. **Это не прогноз чистой прибыли**: НДС, налоги, логистика, обеспечение и прочие расходы не рассчитываются. Заявка на тендерную площадку не отправляется.

### Этап 6. Контроль
Таблица сроков и статусов. Статусы обновляются вручную: «Отобран», «Подготовка», «Подано», «Победа», «Проигрыш». Расчёт дней до дедлайна использует системную дату компьютера. Автоматических уведомлений нет.

## 4. Сохранение и экспорт

- «Экспорт CSV» вверху экрана выгружает **текущее пространство** для Excel. Опасные для таблиц формулы экранируются.
- «Бэкап JSON» выгружает **всю** локальную модель: пространства, настройки, лоты, статусы и заметки.
- На этапе «Контроль» есть «Восстановить JSON». После подтверждения содержимое заменит текущую базу браузера.
- Данные хранятся в localStorage. При очистке хранилища браузера они пропадут. Браузеры и устройства **не синхронизируются**. Совместного режима пока нет.

## 5. Установка и публикация в GitHub Pages

Проект содержит готовые статические файлы index.html, styles.css и app.js. Зависимости и сборка Node.js не требуются.

1. В GitHub откройте https://github.com/GRaVERooT/tenderBOLT/settings/pages .
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте https://github.com/GRaVERooT/tenderBOLT/actions/workflows/pages.yml .
4. Если автоматического запуска не было: **Run workflow → main → Run workflow**.
5. Посмотрите лог job «Deploy». **Только зелёный успешный деплой и открывающийся сайт подтверждают публикацию**.

**Ограничение тарифа:** в GitHub Free Pages доступен для публичных репозиториев; публикация из приватного репозитория требует подходящий GitHub Pro, Team или Enterprise. Репозиторий сейчас Private. Не делайте его публичным без осознанного решения владельца. Даже при Private исходном репозитории Pages-сайт может быть публичным.

## 6. Проверка

1. Откройте сайт и войдите в демо; неправильный пароль должен давать сообщение об ошибке формы.
2. Переключите рабочее пространство, создайте новое.
3. Добавьте лот вручную, сделайте CSV импорт.
4. Смените критерии, сравните баллы.
5. Отберите лот, добавьте заметку и себестоимость.
6. Отметьте пункты чек-листа, переведите на «Подано».
7. Скачайте CSV и JSON, обновите страницу; данные должны остаться.
8. В тестовом пространстве проверьте восстановление JSON.

## 7. Архитектура промышленной версии (отдельная работа)

- Backend с настоящим Identity Provider, серверными сессиями, MFA, RBAC, аудитом.
- PostgreSQL и раздельными правами доступа для каждого клиента и пространства.
- Официальные API и разрешённые выгрузки тендерных площадок, очереди, планировщик и мониторинг ошибок.
- Хранилище файлов ТЗ и объяснимый AI-анализ документов.
- Согласования, контроль дедлайнов, финансовая модель, шаблоны КП.
- Защита персональных данных, секретов, резервное копирование и тесты.

Версия v0.1 доказывает UX процесса, но не готова к промышленной эксплуатации.
