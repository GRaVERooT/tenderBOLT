# tenderBOLT ⚡ — публичный UX-прототип v0.7

**Интерактивный макет:** https://graveroot.github.io/tenderBOLT/

**Классическая демонстрация v0.2:** https://graveroot.github.io/tenderBOLT/classic.html

> Публичный сайт — только статический UX-прототип на HTML/CSS/JS. Он **не подключён** к приватной VM, PostgreSQL, API Госзакуп или реальным компаниям. Все лоты, сотрудники, финансовые показатели и записи аудита в макете вымышленные. Нельзя вводить настоящие токены, пароли, коммерческие сведения или клиентские данные.

## Что показывает новая версия

- Раздельные кабинеты **руководителя** и **оператора** с переключением роли на верхней панели для демонстрации. Это **симуляция ролей**, не настоящая авторизация.
- **Настраиваемые дашборды** с независимым набором и порядком виджетов для каждой роли.
- **Лоты и проекты:** классификация, статусы, приоритеты, сроки, ответственное лицо, визуальный шестистадийный процесс. Учебные лоты можно создавать и редактировать.
- **Карточка проекта:** вручную обогащаемые сведения, требования, риски, следующий шаг, поставщик, технология, метки, связи с другими проектами и журнал действий.
- **Задачи:** создание и завершение задач, дедлайны, отображение на личном дашборде.
- **Граф знаний:** интерактивные узлы проектов, заказчиков, поставщиков, технологий и тегов, поиск, масштабирование и просмотр соседей.
- **Аналитика руководителя:** финансовые ориентиры, конверсия известных исходов, загрузка команды и полнота данных. Оператор не видит управленческую аналитику.
- **Журнал аудита:** учебные записи действий, фильтр по типу/результату и экспорт JSONL локально из браузера.
- **Источники:** безопасная демонстрация состояний проверки Госзакуп без ввода или сохранения API-токена.

Для сравнения прежней версии используйте ссылку **«Классическая версия v0.2»** в боковом меню или [classic.html](./classic.html). Исходные `app.js`, `styles.css` и прежняя [инструкция MANUAL.md](./MANUAL.md) сохранены без изменения. Классический интерфейс использует отдельное хранилище браузера и продолжает работать независимо от нового прототипа.

## Сценарий знакомства

1. Откройте макет как руководитель: дашборд, согласования, финансы и аналитика.
2. Переключитесь на оператора: его задачи и персональные проекты.
3. Откройте **Лоты и проекты → TB-000124**: карточка, стадийная шкала, поле «Риски».
4. Добавьте тег и задачу, затем откройте **Граф знаний** и **Аудит**.
5. Вернитесь к руководителю и проверьте отличия в доступных разделах.

Редактирование и учебный аудит сохраняются только в `localStorage` текущего браузера под отдельным ключом `tenderbolt_public_prototype_v07`. Кнопка **«Сбросить»** удаляет изменения прототипа и восстанавливает учебные данные. Синхронизации между браузерами нет.

## Приватный продукт

Production-пилот, серверные роли, действительное шифрование API-токенов, изоляция компаний, PostgreSQL и очередь экспорта подписанных аудиторских событий находятся в **приватном** репозитории `GRaVERooT/tenderBOLT-prod` и на отдельно разворачиваемой Ubuntu VM. Публичный сайт **не содержит приватный backend и не управляет VM**.

CI в `.github/workflows/verify.yml` проверяет синтаксис обеих версий JavaScript и основные сценарии нового макета. Публикация выполняется `pages.yml` при обновлении `main`.
