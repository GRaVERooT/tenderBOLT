# tenderBOLT ⚡

**tenderBOLT v0.1** — демонстрационное веб-приложение для организации закупок Казахстана: шесть этапов от источника до контроля, рабочие пространства, учебные лоты, поиск, ручной импорт CSV, скоринг по правилам, экономическая оценка, статусы, CSV-экспорт и JSON-бэкап.

**Репозиторий:** https://github.com/GRaVERooT/tenderBOLT  
**Ожидаемый URL Pages после успешного развёртывания:** https://graveroot.github.io/tenderBOLT/  
**Мануал:** [MANUAL.md](./MANUAL.md)

### Шесть этапов

1. Источники — список и переключатели (без автоматического сбора).
2. Сбор лотов — таблица, поиск, добавление вручную и CSV-импорт.
3. Анализ ТЗ — правило оценки по фразам, бюджету и дедлайну (не анализ файла ТЗ).
4. Отбор — статусы и заметки.
5. Предложение — предварительная оценка себестоимости и чек-лист.
6. Контроль — дедлайны и ручной жизненный цикл.

Данные хранятся в **localStorage**, не на сервере. Для переноса используйте «Бэкап JSON» и «Восстановить JSON». Совместной работы пользователей в v0.1 нет.

### Публикация

В репозитории находится workflow [.github/workflows/pages.yml](./.github/workflows/pages.yml). В GitHub откройте [Settings → Pages](https://github.com/GRaVERooT/tenderBOLT/settings/pages), выберите источник **GitHub Actions**, затем проверьте [Actions](https://github.com/GRaVERooT/tenderBOLT/actions). Для Private репозитория нужен поддерживаемый тариф GitHub. Не меняйте видимость без решения владельца.

### Запуск локально

Откройте index.html в браузере либо раздайте текущую папку любым статическим HTTP-сервером. Сборка и зависимости не требуются.

### Для полноценного продукта

Потребуются backend, БД PostgreSQL, серверная авторизация и RBAC, интеграции официальных закупочных API, очередь фоновых задач и анализ реальных ТЗ. Подробнее — в [мануале](./MANUAL.md).
