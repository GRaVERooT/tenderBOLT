# tenderBOLT ⚡ — v0.2

**Сайт:** https://graveroot.github.io/tenderBOLT/

**Инструкция:** [MANUAL.md](./MANUAL.md)

Платформа для организации работы с тендерами Казахстана. Источник данных в этой версии — **только Госзакуп РК**. Автоматический сбор через официальный API пока не подключён. Реестр начинается пустым, **без синтетических или учебных закупок**.

## Возможности

- Шесть этапов: **Обзор → Сбор лотов → Анализ ТЗ → Отбор → Предложение → Контроль**.
- Отдельное боковое меню **«Подключение к источникам»** — сведения об одном источнике, API и требования к подключению.
- Внесение лотов вручную или импорт CSV с обязательными полями: **number;title;customer;budget;deadline;lot_url;tz_url**.
- Для каждого лота — **отдельные URL самого лота и его ТЗ**.
- Анализ ТЗ: выберите конкретный лот, откройте документ по ссылке, прикрепите файл локально (PDF, DOC, DOCX, TXT, XLS, XLSX, RTF), скопируйте персональный промпт и используйте его в ChatGPT, Claude, Gemini, Perplexity либо Microsoft Copilot.
- Прозрачный скоринг по метаданным, заметки, отбор, предварительная финансовая оценка и контроль статусов.
- CSV-экспорт и JSON-бэкап.

## Хранение и ограничения

Лоты и настройки сохраняются в localStorage браузера, а прикреплённые файлы ТЗ — в его IndexedDB. JSON-бэкап содержит сведения о файлах, но **не их содержимое**. Удаление данных браузера уничтожит локальную базу. Синхронизации с другими устройствами или пользователями пока нет.

Для подключения Госзакуп необходим серверный коннектор и токен авторизации. См. [официальный порядок доступа к API](https://ows.goszakup.gov.kz/help/) и [документацию v3](https://procurement.gov.kz/ru/developer/ows_v3). Не храните токен в публичном JS GitHub Pages. Связь ТЗ с лотом пока подтверждает пользователь вручную, а не автоматическая сверка на портале.

Исходный код размещён в [GitHub](https://github.com/GRaVERooT/tenderBOLT); публикация через [Pages workflow](.github/workflows/pages.yml).

При обновлении со старой версии синтетические DEMO-лоты исключаются, а введённые пользователем лоты сохраняются; при необходимости их ссылки следует дополнить.
